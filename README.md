### 🛡️ [SentientGate: AI-Powered Security Gateway](https://github.com/shrihari7396/SentientGate--AI-Powered-Runtime-Security-for-Cloud-Native-Microservices)

**AI-Powered Security API Gateway**

A six-microservice, event-driven API gateway for real-time threat detection, adding just 2–3 ms of latency per request.

**Key Design Decisions:**

* `Detection` → Strategy-based threat detection with circuit breakers.
* `Blocking` → Redis-backed dynamic blacklist using cryptographically signed Visitor IDs.
* `Analysis` → Kafka event processing, gRPC behavioral-history retrieval, and local Ollama LLM heuristics for complex events.
* `Deployment` → GitHub Actions pipeline for automated testing, Docker image publishing, and Kubernetes deployment; KEDA scales Kafka consumers based on lag.

**Highlights:**

* ⚡ Kafka-based threat detection with measured request-path overhead of 2–3 ms.
* 🪪 Cryptographically signed Visitor IDs and Redis-backed dynamic blocking.
* 🚀 gRPC behavioral history and local Ollama-assisted heuristic analysis.
* ☸️ KEDA autoscaling based on Kafka consumer lag.

### 🥉 [Centralized KYC Verification Platform](https://github.com/shrihari7396/Centralized-KYC-System-Backend)
**Consent-Driven Distributed Identity Platform**

A six-service platform that streamlines consent-driven KYC verification with OTP checks and bank approval, while downstream workflow processing runs asynchronously.

**Key Design Decisions:**
- `Event-Driven` → Kafka decouples services and returns immediate responses while onboarding continues asynchronously, with persistent messaging and retries.
- `Security` → JWT authentication, RBAC, OTP verification, database-level encryption, and TTL-based sessions.
- `Lifecycle` → Automated KYC revocation, renewal, and consent-based data sharing with strict access controls.

**Highlights:**
- 🔐 Consent-based identity sharing with strict access controls.
- ⚡ Non-blocking Kafka workflows with persistent messaging and retry mechanisms.
- 🏛️ OTP verification and bank approval in a six-service platform.
